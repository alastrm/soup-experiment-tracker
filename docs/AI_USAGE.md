# How I used AI

I used Codex extensively to implement the backend and frontend, review the architecture, generate tests, debug failures, and prepare documentation. I chose the stack, set the scope and UI direction, reviewed the reported results, and guided each phase. Codex executed the automated tests and load benchmarks cited here; I am not presenting those runs as tests I personally executed. Codex revised generated code and tooling after real failures, including SSE cleanup and load-generator overhead. The repository includes the actual output, failed runs, and known limitations.
